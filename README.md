Fundamentals of Data Science – Lab Experiments
A collection of 20 Python-based laboratory experiments completed as part of the Fundamentals of Data Science course at Rajalakshmi Engineering College.
About the Project
This repository contains practical implementations of fundamental Data Science concepts using Python. It covers data collection, data preprocessing, visualization, statistical analysis, and machine learning algorithms.
Each experiment is organized into a separate folder containing Python source files, datasets (where required), and generated outputs.

Installation and Setup
1. Clone the repository
git clone YOUR_GITHUB_REPOSITORY_URL
cd FDS-Lab-Experiments

2. Create a virtual environment
python -m venv .venv

3. Activate the environment (Windows)
.venv\Scripts\Activate.ps1

4. Install the required libraries
pip install -r requirements.txt

Running an Experiment
Navigate to the experiment folder and execute the required Python file.
Example:
cd Experiment-20
python 20c_kmeans_clustering.py

Generated results are saved in the respective experiment's outputs/ folder.
