## 🧠 ABOUT THIS REPOSITORY

This repository contains practical implementations of the **CS23334 – Fundamentals of Data Science Lab** course.

It documents the complete practical learning process, from data collection and preprocessing to exploratory data analysis, statistical inference, visualization, and machine learning.

Each experiment includes Python source code and corresponding execution outputs.

### 🎯 Learning Objectives

- 📌 Understand fundamental concepts of Data Science.
- 🧹 Perform data cleaning and preprocessing.
- 📊 Explore datasets through visualization.
- 📈 Understand statistical inference and analysis.
- 🤖 Implement fundamental machine learning algorithms.
- 💻 Develop practical Python programming skills.

## 🚀 HOW TO RUN THE EXPERIMENTS

### 1. Clone the repository

```bash
git clone https://github.com/vishweshwaranbalasundaram/FDS-Lab-Experiments.git
```

### 2. Navigate into the project

```bash
cd FDS-Lab-Experiments
```

### 3. Create virtual environment

```bash
python -m venv .venv
```

### 4. Activate environment (Windows)

```powershell
.\.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run an experiment

```bash
python Experiment-01/1a_job_trends.py
```
